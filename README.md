# Shenglei Fang — Academic Website

Personal academic website for Shenglei Fang, built with Hugo and HugoBlox.

The site includes research interests, selected publications, education,
professional experience, and contact links. It is configured for deployment to
GitHub Pages from the `main` branch.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```
